# WatchMind / watch_health

以 Apple Watch 和 iPhone 为入口、端侧优先的个人健康与情绪管理应用。

## 产品文档

- [PRD v0.2：端侧优先重建版](docs/WatchMind_PRD_v0.2.md)

PRD 根据“Apple Watch行为记录”对话摘录重写，覆盖产品范围、数据与算法、设备同步、隐私、验收及 12–16 周实施计划。它不是旧附件的逐字副本。

## 当前状态

项目处于需求设计阶段，尚无应用代码、依赖或可运行测试。原生应用开发与真机验证需要兼容的 Mac、Xcode、iPhone 和 Apple Watch；Linux 云环境用于文档和代码协作。

下一步按 PRD 的 DEV-01 确认设备与签名能力，再搭建 iPhone / Watch 应用工程。
