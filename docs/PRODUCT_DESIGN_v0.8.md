# v0.8：产品聚焦、视觉与界面重构

日期：2026-10-27（北京时间）。本轮已有对应SwiftUI代码和HTML视觉参考；原生效果仍需Mac / 真机验收。

## 1. 核心卖点

**身体变化时，留住真实片刻。**

面向想了解身体变化与日常经历联系、又不愿持续手工打卡的人。以用户主动开启的观察为起点，连接新鲜身体信号、实际录下的原话和本人反馈，提供可以回溯证据的回顾。

三条价值主张：

- **变化触发**：获得足够新鲜心率样本并满足前台等条件后，可以记录触发之后的声音。没有预录，也不承诺全天无遗漏。
- **原话可查**：事件、人工标记、确认高光都有来源入口；用户可以核对、纠正、删除。心率、本人感受与待验证解释分开。
- **本机处理**：当前没有云端接口、账号或分析SDK。转写与可用模型均在本机执行，支持明确的规则降级。可选清理声音后，界面保留真实可用状态。

不把健康总分、持续打开App、连续打卡天数作为本轮核心目标。打开后看懂当下、找到原话、知道下一步是否有必要处理，比增加功能入口更重要。

## 2. 产品功能优化（已实现）

### F36：今天页与实际资料摘要

- 首页顺序为日期与轻量人物入口 → 观察主卡 → 需要核对的任务 → 今日心率事件 / 主动标记 / 确认高光 → 可展开曲线 → 最近真实片刻 → 有依据时的回顾入口 → 身体趋势 / 全文找回。
- 主卡依据实际状态提供开启观察、标记、续录、查看处理进度或身体线索。档案不可写时明确说明并引导检查，不给一个无法生效的开启按钮。
- 今日计数按当前日历日期与真实 / 模拟范围筛选；人工标记可来自前一日开始的有效录音。候选高光、悬空来源和其他范围不计入。
- 待核对任务按录音所有者去重，包含失败 / 部分 / 延后和待清理；不把关联标记当另一录音，也不把已清理的声音误报为可重试。这个计数针对全部本地历史，不声称只属于今天。
- 最近片刻同时考虑心率事件、人工标记与确认高光；今天没有资料时显示真实空态，不拿昨天当今天。不会根据心率生成情绪或健康总分。
- 首页回顾按钮进入「回顾」Tab并明确选择今天，避免原先浏览历史日期后误整理另一日。

### F37：共享视觉系统与可访问性

- 共享AppTheme、AppCard、PrimaryActionStyle、StatusPill、SectionHeading和FeatureRoute，统一间距、圆角与信息层级。
- 浅色用暖白背景、白色卡片、森林绿强调色；深色用深绿背景、分层表面、浅绿链接。取消强制浅色；主按钮使用固定深绿与白字，正文 / 次要文字采用系统动态语义色。
- 录音和异常使用各自状态色，并总配合图标与文字，不仅靠颜色表达。
- 主操作最小48pt，关键图标 / 小时按钮至少44pt。常规字号统计可并列，大辅助字号改为单列；状态和卡片脚注通过ViewThatFits换行。
- 人物缩小为顶部定制入口，不再占据观察主动作之前的大块位置；人物表情仍是装饰，不推测情绪。
- 标记成功写盘后可触发系统轻反馈；清空标记ID不触发。小时跳转在减少动态效果设置下不加动画。

### F38：证据优先的导航与阅读

- 底部四页改为「今天 / 片刻 / 回顾 / 我的」，没有增加主Tab；原设置在「我的」，没有新增账号。
- 原来的零散链接改为带说明的路线卡；高级音频 / 算法 / 语言 / 数据管理继续留在二级界面，原功能未删除。
- 事件卡先显示时间与处理状态，再显示该事件附近的实际原话，其后是心率变化与本人确认；不把长录音开头的无关文字当成此刻上下文。
- 人工标记卡优先显示本人备注，否则展示附近已有文字，没有时保持空态。时间与来源入口均保留。
- 片刻页先提供找回原话的入口；心率曲线可展开。小时导航平常只显示时分，遇到重复小时才显示时区偏移，减少噪声且保留夏令时区分。
- 回顾页依次呈现日期、整理动作、实际回顾、可展开依据、本人反思、可展开覆盖详情。规则摘要入口明确保留，不把生成模型设为唯一通路。
- 顶部录音状态条改为紧凑控制区：状态 / 本次时限、直接标记、暂停后继续、操作菜单中的结束 / 结束观察、真实计时进度。整理中可打开处理中心的独立导航Sheet，避免在NavigationStack外放失效的NavigationLink。

## 4. 验证范围

核心新增5项测试验证今日范围、跨日所有者、待处理去重、无资料空态、最近人工片刻与模拟隔离；不以测试硬编码视觉实现。

HTML用Chromium检查模拟操作、搜索、回顾、四页、双语，以及320 / 390 / 430宽度 × 深浅主题 × 普通 / 大字 × 中英 × 四页，共96种组合的整页横向溢出。输出两张注明模拟的参考图。浏览器验证不等于原生SwiftUI类型、Dynamic Type、VoiceOver或iPhone布局通过。

本轮不改变触发阈值、音频时限、数据保留、清理策略或权限。Mac构建与真机需要检查新主题、系统深色、辅助字号、导航栈、触觉反馈和完整录音状态条。

## 5. 后续建议（未实现）

- 更短的首次体验：以真实首次授权与第一次有效片刻验收，而不是假进度条。
- 根据本人已确认记录组织可追溯的周回顾；仍保留缺失，不推断因果。
- 让小调整与本人结果更容易复盘，不用连续打卡制造负担。
- 优先完善本地导出 / 恢复，再增加更多数据入口；正式桌面图标仍需独立设计与配置。
- 声音检测准确率、功耗、长录音及后台能力继续以真机验证为前提，视觉改版不代表它们已解决。
