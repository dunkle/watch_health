## 2. 新增实现 F33–F35

### F33：一天的数据拼图

按本地Calendar的真实一天生成10分钟块，通常144块，夏令时日会变化。每块只显示有依据的信号：

- 橙色：块内存在有效的近5分钟活动聚合，步数至少20或能量至少2kcal；它是活动线索，不指认具体行为。
- 绿色：存在实际心率样本，但无上述活动线索。
- 灰色：无可用线索。不能解释为休息、平静、睡眠或没有经历。

点击可查看时间范围与心率点数量。窗口结束时间附近的聚合可能覆盖前一块，因此不把颜色当成连续、精确的动作识别。

未使用虚构补点、屏幕使用、定位或录音外的声音监听。当前睡眠估算是日级指标，不填满夜间方格冒充连续检测。

### F34：个人健康趋势与可选安排

展示睡眠估算、HRV、腕温的近14天实际样本点、来源时间、新鲜度与可用个人基线。基线至少5个历史数据日，先每日中位数再跨日中位数；多种命名来源混用时不生成可比基线。

不累加重叠的5分钟步数 / 能量窗口来伪造日总量，不建立“身心能量总分”。图上的日期和缺失保持可查。

建议按单一优先级提供：最近新鲜睡眠估算低于70时，邀请保留休息空间；否则如新鲜HRV较可比基线低至少10ms，邀请结合睡眠与本人感受考虑安排；依据不足时明确不建议改变活动。阈值为可解释工程启发式，不是医学或训练标准，不从HRV确定心理压力。

本版只在用户打开页面时展示建议，不发通知，不自动减训练强度，不代替医疗或运动专业评估。

### F35：一个小调整与结果回顾

用户主动创建一个计划，同一模拟 / 真实范围内最多一个进行中的计划。可填写本人尝试结果、结束和删除；不要求每日输入，不设置连续天数或排名，不自动发送提醒。

计划与确认反思、身体样本分开。系统建议不会自动创建计划。结果属于本人记录，不能宣称改善由该计划导致。

## 3. 与本次其他功能的连接

- 从现在页进入「健康趋势与日常安排」，从建议进入「我的小调整计划」。四个主Tab保持原样。
- 「高光与本地搜索」浏览证据、手动人物与来源记忆；原话快照不覆盖Speech转写。源转写变化时确认撤回，记忆停用，等待本人复核。
- 每日回顾新增人工标记与确认高光作为当天依据；启用且来源有效的记忆仅给Apple端侧模型作历史背景，规则摘要只用当日证据。反思文本独立保存，不自动充当事实。
- 覆盖说明分别列观察开启、实际录音、成功处理、失败与跳过范围；已知区间去重并按日裁剪。处理成功区间不代表说话时长、准确率或生活代表性。
- 语音筛选、资源延后与音频清理的实现范围见统一功能文档；原始音频清理不会删除人物、高光、文字或健康数据，删除整条来源会清理证据引用并停用相关记忆。
