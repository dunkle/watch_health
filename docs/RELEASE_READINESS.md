# v0.10 对客发布验收

日期：2026-10-28（北京时间）。本表用于形成可验收的交付，不表示应用已通过苹果审核或真实设备验证。

**R01–R12代码修复和可执行回归已完成，公开发布验收仍待完成。** [修复记录](reviews/REMEDIATION_v0.10.md)说明实现与测试；[原始报告](reviews/RELEASE_REVIEW_v0.9.md)保留当时失败证据。以下真实平台 / 身份 / 政策 / 模型与运营事项不能由代码修改代填。

## 已具备的实现

- 本机优先记录 / 转写 / 每日回顾；可选的选段与多信号AI复盘。
- 发送前可查完整依据，云端逐次确认，模型与端点不自动切换。
- 钥匙串密钥隔离、禁止重定向、输入 / 输出 / 存档数量界限、取消与错误反馈。
- 复盘来源快照、来源删除联动、音频复用、分项空间统计、文字档案导出。
- 配套受控内测额度网关和自动化测试；尚未部署真实服务。
- 中英资源、深浅色共享主题、隐私清单、正式图标、隐私 / 支持入口、原生CI测试目标与构建配置。

## 发布阻断项（尚未验收）

1. **Mac原生编译**：`git pull --ff-only && ./scripts/setup-mac.sh`，Xcode26+完整SDK。语法解析和Linux替身不验证SwiftUI重载 / Apple API。修复所有实际error，再签名安装两端。
2. **真机闭环**：见[设备计划](Device_Test_Plan.md) v0.9，录音、来电 / 音乐 / 蓝牙 / 锁屏 / 杀进程、端侧Speech和FoundationModels、健康权限与真实样本逐项测量。没有24小时稳定性或耗电合格结论。
3. **AI供应商联调**：使用受控非私人测试数据验证OpenAI / DeepSeek / 目标兼容服务的模型权限、计费、超时、取消、限流与中英文质量。核实模型名与协议，替身测试没有调用这些供应商。
4. **免费额度运营**：部署TLS服务、付费上游、个人身份 / 令牌发放撤销找回、费用上限、滥用与负载防护、恢复和审计。当前默认本机模型无API费，但不是运营平台已赠送第三方额度。
5. **数据可靠性 / 容量**：1小时及长录音、200份复盘、大量历史全文下测启动 / 增量分片保存 / 首次迁移 / 内存峰值，存储不足及写盘失败必须不破坏旧档案。JSON导出没有音频和导入恢复，不得宣传完整备份。新增分片与迁移已通过真实临时FS测试，但设备上的大档案启动 / 保存 / 清理仍需实际容量门槛。
6. **隐私和商店材料**：真实主体 / 联系方式 / 隐私政策 / 用户协议、第三方供应商保留及训练政策、健康数据最小化和单独同意、录音知情同意、删除流程、App Store隐私标签、年龄等级、App Review说明、签名Team / Bundle ID / 已补齐AppIcon的Archive验收 / 真机截图。当前PrivacyInfo清单是保守实现材料，必须与最终实际数据处理核对。
7. **可用性**：中英、动态大字号、VoiceOver、深浅色、小屏和弱网、空态 / 无权限 / 模型未就绪 / 源删除 / 超限 / 取消、文件导出取消与重试。HTML设计稿不作为原生验收证据。
8. **内测发布**：完成上述关键阻断后Archive / Validate App / TestFlight，少量已知用户验证后再公开。不得把未证实的身体情绪推断宣传为准确识别或医疗功能。

## 明确未实现

第三方模型文件下载和本机第三方推理引擎、Watch独立录音、全天后台自动开麦、说话人自动身份识别、逐字音频剪辑导出、完整备份恢复、注册订阅、医疗告警。可配置本机兼容模型服务不等于App内已经包含模型运行时；不能向用户展示无法实际工作的下载按钮。

## 推荐首发范围

先面向明确同意的自用 / 受控内测用户：前台变化触发与手动记录、端侧转写、可核对片段回顾、可选个人密钥AI服务。确认设备兼容与数据可靠性后，逐步开放运营额度与更长会话。产品文案应围绕具体片刻和可回溯依据，保留“不知道”和用户纠正。
