# 真机运行与验收

## 安装

设备信息来自用户：M3 Pro Mac、iPhone（用户描述为18PM）、Watch（用户描述系统为12），均为最新系统。实际型号、完整 OS build、Mac 的 macOS、Xcode SDK 和开发者账号能力仍需在设备上核对；不要据此假定模型或后台能力。

1. 在 Mac 上安装兼容的完整 Xcode，打开一次，接受许可并安装 iOS/watchOS 平台和配对设备支持。
2. 克隆仓库，运行 `./scripts/setup-mac.sh`。XcodeGen 配置会生成工程和 Info.plist/entitlements；生成文件不需要手工修改。
3. 打开 `WatchMind.xcodeproj`，在 Signing & Capabilities 中为两个 target 选择自己的 Team。将 iOS bundle ID 改成唯一值，如 `com.yourname.watchmind`；Watch ID 改成其子 ID，并同时更新 `WKCompanionAppBundleIdentifier`。建议直接修改 `project.yml` 后重新生成，让设置可重复。
4. iPhone 与 Watch 开启所需开发者模式并配对。选择 iPhone 真机运行手机 app，再选择配对 Watch 运行手表 target。
5. 若需要 Apple 端侧大模型，使用包含 FoundationModels 的 Xcode 26+ SDK，并在真机检查 Apple Intelligence 可用性。用较旧 SDK 编译时不包含该代码，规则摘要仍可用。
6. 无需 API Key、后端、账号服务或第三方包。签名账号是否允许所需 HealthKit 能力，以实际 provisioning 为准；不要求在聊天中提供密钥。

## 演示与真实模式必须分开

手机“现在→查看模拟记录”可以演示完整页面、文字线索、本人确认和规则摘要。所有模拟数据有明确标识，不播放不存在的录音，也不计入真实记录。退出演示后才可开启传感器观察。

## 真实闭环

- 手机“开启观察”，阅读并同意本次录音行为，允许麦克风、语音识别、健康读取。
- 手机保持前台、屏幕可见，放在能听清本人讲话的位置，确保周围人知情。
- 自然步行时可在 Watch 开始“步行观察”。不应为了触发而过度运动、憋气或制造异常心率；正常使用中没有触发也是有效结果。
- 等待至少5个新鲜样本建立短期基线。遇到自然波动，手机出现录音条；说一段同意被记录的话，手动停止或等待30秒。
- 检查录音、转写和分段、原始音频播放；标记本人感受，再生成每日摘要并核对证据。
- Watch 结束并保存步行，手机结束观察。此后心率变化不应再录音。

## 当前尚未提供

全天可靠的后台录音、Watch 端录音、云端 AI、备份恢复、情绪医学识别、睡眠模块、远程真机连接和自动安装。当前云机器无法验证 Apple SDK、签名、硬件或设备上的模型就绪状态。


## 复查修复的重点回归

- 录音期间来电：录音条与忙碌状态应结束，片段标为中断，可以随后重试，不依赖录音完成 delegate。
- 连续点两次重试：只有一个转写任务；模拟旧任务结束回调时不得结束或覆盖新任务。
- 授权弹窗期间结束观察或进入模拟模式：授权返回后不能恢复观察，退出模拟也不能自动录音。
- 手表点击结束后：保存期间只显示等待，不允许新建运动；旧 session 的回调不能清空新 session。
- 锁屏期间收到事件或转写完成：文件保护仍为 complete，待保存状态保留内存；解锁后重试，不永久禁用采集。锁屏期间进程被终止，尚未写盘的数据可能丢失，不能承诺已保存。
- 冷启动时保护数据不可读：等待解锁再加载，不把读取失败当空库。磁盘满和损坏档案仍应报错并停止写入。
- 文本“不开心”“没有压力”“unhappy”“not happy”不产生相反的肯定线索；复杂否定、讽刺仍不支持可靠判断。


## 双语与构建进度回归

- 手机设置选择 English：四页、弹窗、记录状态和感受标签切为英文，重启后保留。
- 切回简体中文、选择跟随系统，核对中文/英文系统偏好与其他语言的英文回退。
- 核对长英文按钮、最大辅助字号和 Watch 小屏，不应截断重要的授权说明与停止按钮。
- 手机更改语言后连接 Watch，确认可收到语言偏好；Watch 独立选择可能在手机下一次同步时被覆盖。
- 分别用中文/英文新建自然触发录音，验证 zh-CN/en-US 本地识别；缺少离线能力时不上传。
- 切换语言后重试旧录音，仍使用录制时的语言；旧版无语言字段的录音按原来中文识别。
- 摘要在当前语言生成，切换后不冒充已有另一语言的摘要；原始转写不翻译、不修改。
- 在系统设置切换 App 语言并请求尚未请求的权限，检查 InfoPlist 双语说明；应用内语言切换不改变系统已选的权限弹窗语言。
- 安装脚本核对5个阶段、耗时与长任务15秒心跳。测试或原生编译失败必须保留非零退出码，不能显示最终成功。
