## 额外完成的可靠性能力

- 每45秒转写检查点、暂停当前识别 / 导出、继续已完成范围、显式全部重识别。任务退出前保留占用，磁盘检查点失败停止后续识别。

- AI输入明确单位 / 聚合 / 估算语义，持久样本 / 设备ID不外发；结果保存非敏感端点来源。
- 正式iPhone / Watch原创图标；隐私说明、发布者政策 / 支持入口、用户主动诊断分享；真实原生测试目标与结果bundle。
- 统一手机 / Watch Bundle ID派生，静态发布检查阻止默认身份、缺政策支持和不匹配Team。

## 同机容量验证

脚本`measure-archive-capacity.py`使用合成资料和真实临时文件系统，没有私人数据、音频、AI历史或iPhone测量。单次样本，仅说明当前机器上的保存路径差异。

| 数据 | 完整JSON编码（不含磁盘） | 新增标记增量保存（含临时磁盘） | 本次新分片 / 复用 |
| --- | --- | --- | --- |
| 7天×30分钟、25200词段、60000心率点 | 701.7ms | 38.9ms | 158字节 / 1新分片 / 26复用 |
| 30天×60分钟、216000词段、60000心率点 | 1109.4ms | 22.5ms | 158字节 / 1新分片 / 49复用 |

旧档案首次迁移、改单条很长的录音、全文检索和大批量导出仍有成本；不声称手机持续运行24小时、内存峰值或功耗已经达标。清单和分片必须一起保留，不能单拷archive.json当备份；独立文字JSON导出不含音频 / 密钥，仍无导入恢复。

## Mac验证和正式发布

```sh
git pull --ff-only
./scripts/setup-mac.sh
./scripts/test-native.sh
open WatchMind.xcodeproj
```

模拟器测试不要求付费服务，不录音、不请求HealthKit，不删除记录；真机仍按[设备计划](../Device_Test_Plan.md)测试来电 / 音乐 / 路由 / 锁屏 / 终止、低空间、Speech / SoundAnalysis / HealthKit及长时会话。

在本机发布配置或CI secret中填写真实值，不提交API Key：

- `DEVELOPMENT_TEAM`
- `WATCHMIND_APP_BUNDLE_ID`（Watch ID与companion由此派生）
- `WATCHMIND_OPERATOR_NAME`
- `WATCHMIND_PRIVACY_POLICY_URL`
- `WATCHMIND_SUPPORT_URL`

在Mac导出解析后的Release设置并检查：

```sh
xcodebuild -project WatchMind.xcodeproj -scheme WatchMind -configuration Release -showBuildSettings -json > /tmp/WatchMind-release-settings.json
python3 scripts/check-release-config.py --settings-json /tmp/WatchMind-release-settings.json
```

仓库默认值明确不具备公开发布身份，预检查会失败；静态通过也不能证明站点实际存在、签名正确或已审核。正式发布还需实际政策 / 供应商处理说明、真实接口 / 计费、签名Archive / Validate、TestFlight和真机验收。免费服务仅有代码，仍需运营部署、令牌发放 / 撤销、上游费用上限与监控。
